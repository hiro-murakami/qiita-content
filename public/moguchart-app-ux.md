## TL;DR

- ブラウザだけで使えるガントチャートWebアプリ **[MoguChart (moguchart.jp)](https://moguchart.jp/)** が最新バージョン **v1.1.0** に到達しました！🎉
- 実務での本格運用に欠かせない **WBS（階層ツリー構造・行の開閉）** と **サマリータスク（期間・進捗率の自動集計）** を全面サポート
- **ガントチャート全体の表示倍率ズームシステム**（文字・ヘッダー・バー高さ連動、Chrome風UI、カレンダー横幅の独立設定）や、セグメントボタン導入による **表示設定UIの刷新**
- **公式 Vue 3 ラッパー ＆ エクスポートプラグインのオンデマンド動的インポート（遅延読み込み）** による初期表示高速化とサクサク動作
- **画像プレビューポップアップの快適化（500ms ホバーディレイ ＆ ツールチップ排他制御）** によるちらつき・誤発火防止
- **エクスポート時の表示倍率自動正規化（等倍100%での高画質出力 ＆ 自動復元）** とスクロール位置保持
- **ガントバーの矩形範囲選択（ラバーバンド選択）**、**タスク進捗率の直感的ドラッグ編集**、**担当者設定と閲覧者による進捗更新**、**ZIPアーカイブへの添付画像同梱・完全復元**、**ミニマップ（鳥瞰ビュー）**、**クリティカルパス表示**、**行マーカー**、**画像添付**、**一般公開URL**、**REST API** など、多彩な機能を搭載
- Googleアカウント不要の**ゲストログイン**で、アクセス後1秒ですぐに全機能を試せます

## なぜ作ったのか

コアライブラリである [moguchart-core](https://github.com/hiro-murakami/moguchart-core)（[デモ](https://moguchart-core.vercel.app/)）を自作したことが、すべての始まりでした。

当初は「Web Components製のガントチャートライブラリ」としてライブラリ単体での公開を目指していましたが、開発が進むにつれて **「どれだけ優れたライブラリであっても、実際にプロダクトに組み込まれた姿を見せなければ、その真価は伝わらないのではないか」** と考えるようになりました。

そこで、ライブラリの「究極のデモ」として、そして自分自身が「本当に実務で使いたい」と思えるプロジェクト管理アプリを目指して開発したのが、この **MoguChart** です。

世の中には数多くのプロジェクト管理ツールが存在しますが、多機能すぎて学習コストが高かったり、逆にシンプルすぎてガントチャートとしての表現力が足りなかったりすることが多々あります。これまでの業務で培った Firebase や Vue.js などの技術知見をフルに活かし、「ガントチャートだけを徹底的に、かつ直感的に使えるWebアプリ」という、ちょうどいいニッチを埋めるプロダクトを目指しました。

## こだわったUXポイント

### 1. 🕐 3つの表示モード ─ プロジェクトの粒度に合わせる

MoguChart では、プロジェクト作成時に**表示の粒度**を選べます。

| モード       | 最小単位                  | 使いどころ                                   |
| ------------ | ------------------------- | -------------------------------------------- |
| **時間単位** | 分（スナップ: 5〜60分）   | 1日のイベントスケジュール、短期の作業計画    |
| **日単位**   | 日（スナップ: 3〜24時間） | 一般的なプロジェクト管理（デフォルト）       |
| **月単位**   | 月（最大100年対応）       | 年間ロードマップ、長期プロジェクト、歴史年表 |

「日単位だと粗すぎるけど、時間単位で管理したい作業がある」
「長期計画だから月レベルで10年・20年先まで俯瞰したい」

そんな様々なニーズに、1つのアプリで柔軟に応えられるようにしました。

### 2. 🌳 WBS（階層ツリー） ＆ サマリー自動集計 ─ 大規模プロジェクトもすっきり構造化

中〜大規模なプロジェクトでは、工程やタスクを階層構造（大工程 ＞ 中工程 ＞ 詳細タスク）で整理することが欠かせません。MoguChart では、無制限の階層ツリーをマウスとキーボードで直感的に組み立てられます。

<img src="https://raw.githubusercontent.com/hiro-murakami/qiita-content/main/images/moguchart-v1-release/WBS.gif" alt="WBS.gif">

#### インデント・アウトデントで自在に階層化

行ヘッダーの右クリックメニュー、ヘッダーツールバーのインデントボタン（➡️ / ⬅️）、またはキーボードショートカット **`Tab`** / **`Shift + Tab`** を押すだけで、選択した行を直感的に子行化（インデント）・親階層へ昇格（アウトデント）できます。複数行を選択しての一括インデント・アウトデントにも対応しています。

#### ワンクリックで展開 ＆ 折りたたみ（一括操作対応）

子行を持つ親行の左側には開閉トグルアイコン（**▶** / **▼**）が表示され、配下の子孫行をワンクリックで折りたたみ・展開できます。さらに、ヘッダーツールバーの **📁（すべての親行を折りたたみ）** / **📂（すべての行を展開）** ボタンを使えば、プロジェクト全体を一瞬でコンパクトに俯瞰したり全展開したりできます。折りたたみ状態はプロジェクトごとに自動保存されます。

#### サマリータスク（期間 ＆ 進捗率の自動集計）

子行を持つ親行には、配下の全タスクの「最小開始日」から「最大終了日」までを自動集計した**サマリータスク（山型の集計ブラケットバー）**が自動描画されます。

- **期間加重平均進捗率**: 配下タスクそれぞれの期間に応じた加重平均進捗率を自動算出し、サマリーバー内にプログレス表示および進捗ラベル（例: `65%`）を描画
- **リアルタイム自動更新**: 配下の子タスクの日程や進捗率をドラッグ操作すると、親のサマリーバーもリアルタイムに自動再計算されて連動
- **通常タスクとの2段共存描画**: 親行自身に通常タスクが登録されている場合でも、上段に通常タスク、下段にサマリータスクが2段で並んで描画され、タスク同士が重複せず両方を確認・操作可能
- **サマリーカラー設定**: プロジェクト全体の既定色（デフォルト: `#334155`）に加え、行ごとに個別サマリー色を自由にカスタマイズ可能
- **表示切り替え**: 表示設定メニュー（⚙️）の「サマリータスクを表示」スイッチからワンクリックで表示・非表示を切り替え可能

#### 安全なブロック連動移動 ＆ 循環参照防止ガード

親行をドラッグ＆ドロップで並び替えると、配下のすべての子孫行が**ブロックとして一体となって追従移動**します。また、自分自身の子孫行の内部へドロップするような循環参照（ツリー構造の破綻）を引き起こす移動操作は自動的に禁止・抑止される安全設計となっています。

### 3. 🖱️ ドラッグ＆ドロップですべて完結

タスク管理の操作は、可能な限り**マウス操作だけで直感的に完結する**ようにしています。

#### タスク操作

| 操作                          | やり方                                                                 |
| ----------------------------- | ---------------------------------------------------------------------- |
| タスクの移動                  | バーをドラッグ（上下ドラッグで行間移動も可能）                         |
| 期間の変更                    | バーの端をドラッグ                                                     |
| 進捗率の変更                  | バー端の進捗ハンドルをドラッグ（5%刻みスナップ）                       |
| タスクの複製                  | `Ctrl` / `Alt` + ドラッグ                                              |
| 行の並べ替え                  | 行ヘッダーをドラッグ（親行移動時は子孫行もブロック連動移動）           |
| 行のインデント / アウトデント | `Tab` / `Shift+Tab`、ツールバーボタン、または右クリックメニュー        |
| 行の展開 / 折りたたみ         | 親行ヘッダーのトグルアイコン（▶/▼）クリック、またはツールバー（📁/📂） |
| 依存関係の作成                | バー端のハンドルを他のタスクへドラッグ                                 |
| テンプレートからタスク作成    | サイドバーからチャートへドラッグ                                       |
| 矩形範囲選択                  | 空白背景をドラッグ（Shift/Ctrl/Cmdキーで追加選択）                     |
| 複数タスクの一括移動          | 複数選択（クリックまたは矩形ドラッグ）→ ドラッグ                       |

「右クリックメニュー」と「ダブルクリックで編集」の2つさえ覚えれば、迷わずすべての操作にアクセスできます。

<img src="https://raw.githubusercontent.com/hiro-murakami/qiita-content/main/images/moguchart-app-ux/drag-and-drop.gif" width="400" alt="drag-and-drop.gif">

#### 右クリックメニュー

チャートの空白エリアやタスクバーを右クリックすると、その場所に応じたコンテキストメニューが表示されます。

- **空白エリア**: 新規タスク作成 / 新規マーカー作成 / ペースト / Undo / Redo
- **タスクバー**: 編集 / コピー / 削除 / 画像管理 / コメント
- **行ヘッダー**: 行の追加 / 編集 / インデント（子行にする） / インデント解除 / 配下の行を折りたたむ・展開 / 非表示 / 画像管理 / 削除
- **依存関係の接続線**: 接続線を削除
- **マーカー**: 編集 / 削除

### 4. 🎨 タスクバーの見た目を細かくカスタマイズ

「色分けしたい」はもちろん、MoguChart ではさらに踏み込んだ見た目の設定が可能です。

#### カラーパレット

プロジェクトごとにカラーパレットを定義し、各パレットに**名前**を付けられます。「進行中」「レビュー待ち」「完了」のように意味のある名前を付ければ、チーム内でバーの色の意味が統一されます。カラー選択UIにはスウォッチやプレビュー付きのピッカーを採用し、直感的に色を選べます。

<img src="https://raw.githubusercontent.com/hiro-murakami/qiita-content/main/images/moguchart-app-ux/color-palette.gif" width="400" alt="color-palette.gif">

#### パターン（13種類）

タスクバーの背景に重ねるパターンを設定できます。

> diagonal-stripe / diagonal-stripe-thin / diagonal-stripe-thick / diagonal-stripe-reverse / vertical-stripe / horizontal-stripe / checkerboard / dots / dots-dense / triangle / circle / grid / diagonal-grid

「仮タスクはストライプ」「保留中はドット」のように、色＋パターンの組み合わせで状態を視覚的に区別できます。

#### 枠線スタイル

実線（細/太）、破線（細/太）、点線（細/太）から選べます。パターンと組み合わせることで、モノクロ印刷時にも区別しやすいバーが作れます。

#### バーの影

ドロップシャドウの強さを4段階（なし / 小 / 中 / 大）で調整できます。影を付けるとバーが浮き上がって見え、情報量の多いチャートでも視認性が大幅に上がります。

### 5. 🏁 マイルストーンで節目を可視化

プロジェクト全体の節目（リリース日、デッドラインなど）を縦線＋バッジで表示します。マウスオーバーでハイライトされるため、「この日までに何を終わらせるか」が一目でわかります。

### 6. 📍 マーカー ─ 行レベルの目印

マイルストーンがプロジェクト全体の節目であるのに対し、**マーカー**は各行（タスクグループ）のタイムライン上にピンポイントで配置する目印です。

- 三角形アイコン＋ラベルで、行ごとの重要な日時をマーク
- **3種類のスタイル**: ◀（左向き） / ▶（右向き） / ▼（下向き）
- **5段階のフォントサイズ**: 極小 / 小 / 中 / 大 / 特大
- 16色のプリセットカラー＋カスタム色指定
- ダブルクリックで編集、右クリックで編集・削除（編集中はパルスアニメーションで強調）

「このタスクグループのレビュー期限」「チームごとの中間目標」など、行レベルで細かい目印を置きたい場合に重宝します。

### 7. 🔍 ガントチャート全体の表示倍率ズーム ＆ カレンダー横幅の独立設定

「広い期間を一目で俯瞰したい」「密集したタスクを拡大して細かく調整したい」というニーズに応えるため、柔軟かつ洗練されたズームシステムを搭載しています。

#### 文字・バー・行ヘッダーが美しく連動する表示倍率システム

従来の単なる横方向（カレンダー幅）の伸縮ではなく、ガントチャート全体（カレンダー横幅、行ヘッダー幅、バー高さ、フォントサイズ）が美しく連動して拡大縮小する**表示倍率システム（50%〜200%、標準100%）**を採用しています。チャート内のタスク名・行名・ラベル・進捗バッジ・マーカー・カレンダー日付がフォントスケール連動するため、倍率を変更しても文字がはみ出したりレイアウトが崩れたりしません。

#### Chrome風ズーム操作UI ＆ ワンタッチリセット

表示設定メニュー（⚙️）にChromeブラウザライクなズーム操作グループを配置しています。

- **ワンタッチ伸縮**: `−` / `＋` ボタンをクリックすることで、ステップ単位（50%〜200%）で素早く切り替え
- **キーボードズーム**: **`Cmd/Ctrl + +`（拡大）** / **`Cmd/Ctrl + -`（縮小）** による軽快なズーム操作に対応
- **ワンクリックリセット**: 倍率パーセント表示（例: `100%`）のクリック、またはリセットアイコンボタンで即座に標準（100%）へリセット
- **リセットショートカット**: **`Cmd+0` (Mac) / `Ctrl+0` (Windows)** を押すだけで作業中のどこからでも一発で 100% にリセット
- **マウスホイール連携**: **`Cmd` / `Ctrl` + マウスホイール** で、カーソル位置を中心にシームレスに拡大縮小（画面下部フッターのズームスライダーとも完全連動）

#### カレンダー横幅の独立設定（5段階プリセット）

全体の表示倍率とは独立して、1目盛り（日・月・時間）あたりの基準横幅をセグメントボタンからワンクリックで選択できます。

- **日単位モード**: 極小 (14px) / 小 (20px) / 中 (28px: 標準) / 大 (40px) / 特大 (56px)
- **月単位モード**: 極小 (20px) / 小 (30px) / 中 (40px: 標準) / 大 (60px) / 特大 (80px)（最大100年の超長期スパンにも対応）
- **時間単位モード**: 極小 (60px) / 小 (100px) / 中 (140px: 標準) / 大 (200px) / 特大 (280px)

「文字やバーの大きさは標準のまま、日付のマス目だけをコンパクトにして全体を見通したい」といった現場の要望にも柔軟に応えられます。設定したズーム倍率やカレンダー幅はプロジェクトごとに自動保存されます。

### 8. 🗺️ ミニマップ ─ 全体を鳥瞰し、自在にナビゲーション

大規模なプロジェクトや長期タイムラインでも迷子にならないよう、ガントチャート全体を縮小プレビューできる**ミニマップ（鳥瞰ビュー）**を搭載しています。

- **ビューポートナビゲーション**: ミニマップ内の半透明フレーム（現在の画面表示領域）をドラッグ、またはミニマップ上の任意の位置をクリックするだけで、目的のエリアへ瞬時にスクロール
- **ドラッグリサイズ**: ミニマップ端のリサイズハンドルをドラッグして、チャートのアスペクト比を維持したままサイズを自由に変更可能
- **不透明度（透過率）の調整**: ⚙️ 表示設定メニューから不透明度（20%〜100%）を素早く調整可能。半透明にしておけば背面のタスクを見通せ、ホバー時や操作時には自動で100%になって視認性を保ちます
- **折りたたみ（最小化）**: 右上の「×」ボタンでコンパクトなアイコン（FAB）に折りたため、作業の邪魔になりません
- **進捗状況の自動反映**: 各タスクの進捗率がミニマップ上のバーにも濃淡として自動的に描画され、全体の進み具合を一目で俯瞰可能
- **設定の永続化**: 表示状態・サイズ・不透明度・折りたたみ状態はプロジェクトごとに自動保存されます

### 9. 📊 進捗率のプログレスバー ＆ 直感的ドラッグ編集

タスクごとに 0〜100% の進捗率を設定でき、バー上にプログレスバーとしてリアルタイム描画されます。毎日の朝会で「今どこまで進んでる？」の確認がチャートを見るだけで一瞬で完了します。

<img src="https://raw.githubusercontent.com/hiro-murakami/qiita-content/main/images/moguchart-app-ux/progress-bar.png" width="200" alt="progress-bar.png">

#### マウスドラッグで進捗率を直感変更

ダイアログを開かなくても、タスクバー上の進捗バー右端にある**ハンドルを直接ドラッグ**するだけで、進捗率を直感的に変更できます。

- **5%刻みのスナップ**: マウスを少し動かすだけで「25%」「50%」「75%」などキリの良い数値に気持ちよく吸着
- **安全キャンセル**: ドラッグ中に `Esc` キーを押すと元の進捗率に即座にロールバック
- **Undo / Redo ＆ 共同編集連動**: 進捗率のドラッグ変更も履歴管理され、他のメンバーの画面にもリアルタイムに同期

#### プロジェクト単位の進捗管理ON/OFF

「進捗管理は不要で、純粋な工程表・スケジュール表としてシンプルに使いたい」という場合は、プロジェクト詳細の「編集オプション」タブから**「進捗率管理を行う」をOFF**に設定できます。OFFにすると、バー上の進捗表示や編集ハンドル、ダイアログ内の進捗率入力フィールドが非表示になり、すっきりとした画面で運用できます。

#### タスク担当者（Assignees）機能と進捗更新

タスク編集ダイアログで「担当者」を設定できます（過去に入力したメールアドレスのインクリメンタル補完に対応）。タスクバーにマウスオーバーすると、ツールチップに担当者のメールアドレスがバッジ表示されます。

さらに、**「閲覧者（viewer）」権限のユーザーであっても、自身が担当するタスクの進捗率だけは直接ドラッグ編集で更新できる**よう権限を分離しています。「メンバーに編集権限を渡すとタスク日程や構成を誤って変更されてしまう恐れがあるけれど、進捗報告だけは各自に直接更新させたい」という現場のニーズに最適です。

### 10. 🔗 依存関係の矢印表示 ＆ クリティカルパス

「タスクBはタスクAが完了してから」という依存関係を、矢印付きの接続線（直角折れ線または曲線）で可視化できます。

- **ドラッグで簡単作成**: バーの端にある接続コネクターをドラッグして、依存先タスクにドロップするだけで直感的に作成
- **クリック選択 ＆ 直感削除**: 接続線を直接左クリックすると太線と影でハイライト選択され、中央に表示される「×」ボタンをクリックするか `Delete` / `Backspace` キーを押すだけで瞬時に削除可能（右クリックメニューからの削除にも対応）
- **タスク名入り削除確認ダイアログ**: 接続線を削除する際、「『先行タスクA』から『後続タスクB』への接続線を削除してもよろしいですか？」という確認ダイアログが表示され、誤操作を確実に防止。万が一削除しても Undo（`Cmd+Z`）ですぐに元通り復元可能
- **サマリータスクの自動保護**: サマリータスクは子タスクの集計結果であるため、サマリータスクに対する依存関係の作成・描画は自動的に抑止され、循環依存の発生を未然に防止します

#### クリティカルパス表示

依存関係グラフから**最長チェーン（クリティカルパス）**を自動計算し、該当するタスクバーと接続線を**赤色でハイライト**表示する機能です。表示設定メニューからワンクリックでON/OFFを切り替えられます。

「プロジェクト全体のボトルネックはどこか？」「どのタスクの遅れが納期に直結するか？」を一目で把握できます。

### 11. 🔒 「うっかり操作」を防ぐ充実のガード機能

自由度の高いドラッグ操作ができるからこそ、誤操作を防ぐ仕組みを何重にも用意しています。

- **タスクロック**: 確定済みタスクをロックすると、移動・リサイズ・削除が禁止されます
- **読み取り専用モード**: 表示設定からONにすると、すべての編集操作が無効化されます（会議での画面共有や報告時に最適）
- **行の入れ替え禁止**: プロジェクト詳細の「編集オプション」でONにすると、ドラッグによる行の並べ替え操作が無効化され、行順序の意図せぬ崩れを防止
- **タスク移動の横方向限定**: タスクバーの上下ドラッグ（行またぎ移動）を禁止し、同一行内での日程調整だけに制限
- **WBS循環参照の自動抑止**: 親行をドラッグして自身の子孫行へドロップするような、ツリー構造の破綻・無限ループを引き起こす移動を自動的にブロック
- **サマリータスクの自動保護**: 集計バーに対する直接ドラッグや依存関係の作成を自動抑止し、計算結果の整合性を保持
- **領域外安全キャンセル**: ドラッグ操作中にマウスポインターがチャート外に出た場合、自動で安全にキャンセルされ元の位置に戻ります

### 12. 📸 スナップショットで「あの時の状態」に戻れる

プロジェクトの状態をまるごと保存し、いつでもタイムトラベルできます。

| 機能         | 説明                                                                                  |
| ------------ | ------------------------------------------------------------------------------------- |
| 手動保存     | 任意のタイミングでスナップショットを作成                                              |
| 自動保存     | 5分〜24時間の間隔で自動保存（保持期間も設定可能）                                     |
| 復元         | 過去のスナップショットの状態にワンクリックで復元（WBS階層構造・サマリー色も完全復元） |
| 閲覧         | スナップショットを読み取り専用で安全に閲覧                                            |
| ダウンロード | スナップショットをバックアップファイル（JSON/ZIP）として保存                          |

「昨日の朝会時点ではどうなってたっけ？」を即座に確認でき、「変更を元に戻したい」にもワンクリックで対応できます。

### 13. 👥 リアルタイム共同編集

同じプロジェクトを複数人で同時に開くと、スムーズな共同作業が始まります。

- **アクティブユーザー表示**: 現在開いているメンバーがアバターでひと目でわかる（編集権限者に限定してスッキリ表示）
- **変更履歴パネル**: 他のメンバーの操作内容がリアルタイムにログ表示される
- **パネルの最小化（FAB）**: 作業領域を広く使いたいときは右下の「−」ボタンで円形アイコンに最小化可能。最小化中も新着件数が未読バッジ（赤丸）で通知されます
- **ワンクリックフォーカス**: 変更ログ内のタスク名をクリックすると該当タスクに素早くスクロールし、ダブルクリックで編集ダイアログが開きます

### 14. 📤 多彩なエクスポート

| 形式              | 用途                                                                                    |
| ----------------- | --------------------------------------------------------------------------------------- |
| **CSV**           | 他ツール・スプレッドシートへのデータ連携                                                |
| **Excel** (.xlsx) | 報告書添付、Excelユーザーへの共有（禁止文字サニタイズ対応）                             |
| **PNG**           | スライド資料やドキュメントへの貼り付け                                                  |
| **PDF**           | 印刷・公式なメール添付                                                                  |
| **ZIP**           | プロジェクト全体のバックアップ・移行（**WBS親子階層・サマリー色・添付画像も完全同梱**） |

CSV/Excel エクスポートには行名・タスク名・開始日・終了日・日数・ラベル・説明が含まれます。ラベルフィルタ適用中なら**表示中のデータだけ**がエクスポートされるため、報告用データの切り出しにも便利です。

特に **ZIP エクスポート** では、プロジェクトデータ（WBS親子階層やサマリー色設定を含むJSON）だけでなく、タスクや行に添付された画像ファイル（Cloud Storage 上の実画像）もまとめてアーカイブ内に同梱・バックアップされます。リストア（復元）時にはアーカイブ内の画像が自動的に再アップロードされ、URLや依存関係IDも自動再マッピングされるため、添付画像やツリー構造を含めた完全なプロジェクトの移行・復元が可能です。

## 「地味だけど便利」な機能たち

### ↩️ あらゆる変更を直感的に元に戻せる Undo / Redo（Cmd+Z / Ctrl+Z）

「誤ってタスクを別の行に移動してしまった」「進捗率を間違えて変えてしまった」「タスクや接続線をうっかり削除してしまった」──そんなときでも慌てる必要はありません。

MoguChart では、コアライブラリ（`@mogura/moguchart-core` v1.2.0）の Command パターンと連携し、チャート上で行われるほぼすべての編集操作が自動的に Undo / Redo スタックに記録されます。

- **対応操作**: タスクのドラッグ移動（単一・複数一括・行間移動）、ドラッグリサイズ、タスクバー上の進捗ハンドル操作、タスクの作成・編集・削除、クリップボード貼り付け、行の追加・編集・削除・並び替え・インデント/アウトデント、親行の一括開閉、依存関係線の作成・削除
- **キーボードショートカット**: **`Cmd+Z` / `Ctrl+Z`**（元に戻す）および **`Cmd+Shift+Z` / `Ctrl+Y`**（やり直し）で瞬時に操作を取り消し・再実行
- **ツールバーボタン**: 画面上部のツールバーにも Undo / Redo ボタンを完備し、現在取り消し可能な操作があるかどうかも視覚的に把握可能
- **共同編集との同期**: Undo / Redo を実行した際も、他ユーザーの画面へリアルタイムに変更内容が安全同期されます

### 🔲 矩形範囲選択（ラバーバンド選択）

チャートの空白背景（日付グリッド領域）をドラッグすることで、矩形選択ボックス（ラバーバンド）を表示し、交差・囲まれた複数のタスクバーを一括選択できます。

- **リアルタイム選択**: ドラッグ操作中に交差するタスクバーがリアルタイムに青枠でハイライト選択されます
- **追加選択（Shift / Ctrl / Cmd + ドラッグ）**: 修飾キーを押しながらドラッグすることで、既存の選択を保持したまま追加で範囲選択（複数選択の累積）が可能です
- **オートスクロール**: ドラッグ中にチャート端に近づくと自動的にスクロールし、画面外に広がるタスクもスムーズに選択できます
- **複数タスク操作へのシームレスな連携**: 矩形選択したタスクは、そのまま一括ドラッグ移動、キーボード移動（`Shift + 左右矢印`）、一括コピー＆ペースト（`Cmd+C / Cmd+V`）、一括削除（`Delete`）へ直結します

### 期間スライド

プロジェクト全体の開始日が変更になったとき、**全タスク・全マイルストーンの日付をまとめてスライド**できます。新しい開始日を指定するだけで、プロジェクト期間を維持したまま全体が自動でずれます。進捗率のクリアオプションも備えています。

### プロジェクト複製

「前期のプロジェクトをベースに今期分を作りたい」という場合も、プロジェクト詳細の複製機能でスムーズに対応できます。

1. **プロジェクト名**: 「〜のコピー」から任意の名前にワンクリック変更
2. **日付の連動スライド**: 開始日を変更すると、期間を維持したまま終了日・タスク・マイルストーンの日付が自動追従
3. **進捗率のクリア**: 複製時にタスクの進捗率をまとめてリセット可能

タスクおよび行ヘッダーに画像を添付できます。

- **3つの柔軟なアップロード方法**: ファイル選択 / ダイアログへのドラッグ＆ドロップ / **クリップボードからの貼り付け（`Ctrl+V` / `⌘+V`）**
- **自動最適化**: 5MBを超える画像は自動で最大1920pxにリサイズ＆段階的圧縮
- **快適なホバープレビュー（500ms 表示遅延 ＆ 排他制御）**:

  - マウスクリック時には表示待機タイマーを即座に破棄

  - 仮想スクロールや再描画時もデータ属性（`data-task-thumb` / `data-row-thumb`）により位置ずれなく安定追従
- **ライトボックス拡大表示**: サムネイルクリックで高解像度モーダル表示（キーボードの左右矢印キーで複数画像をページ送り可能）

### 📤 鮮明・高速なエクスポート ＆ ズーム自動正規化

PDF（複数ページ分割対応） / PNG / CSV / Excel / **ZIP（添付画像完全同梱・自動復元）** など、多彩なエクスポート形式をサポートしています。

- **オンデマンド動的インポート（遅延読み込み）**: 重たい画像・PDF変換ライブラリ（`html2canvas-pro`、`jspdf`）を初期バンドルから完全排除。ユーザーがエクスポートボタンを押した瞬間にのみ公式プラグイン（`@mogura/moguchart-plugin-export`）を動的ロードするため、普段の画面表示や操作感が圧倒的に軽快です
- **エクスポート時の表示倍率（ズーム）自動正規化**: 50%〜200%のどのズーム倍率でチャートを閲覧していても、エクスポート実行時に自動で一時的に等倍（100%）に切り替えて高解像度キャプチャを行い、完了後に元の表示倍率へ自動復元。拡大・縮小状態にかかわらず常に鮮明で標準比率の画像やPDFが出力されます
- **スクロール位置保持 ＆ 影補正**: エクスポート処理の一時的なレンダリング更新時にも、ユーザーが作業していたスクロール位置を確実に保持し、カレンダー幅拡張時の影の描画ずれも自動補正されます

## 権限管理 ─ チームでの運用を考えた設計

MoguChart は3段階の権限モデルで、チームでの安全な運用をサポートします。

| 操作                                           | オーナー | 編集者 |          閲覧者          |
| ---------------------------------------------- | :------: | :----: | :----------------------: |
| チャート閲覧・エクスポート                     |    ✅    |   ✅   |            ✅            |
| 担当タスクの進捗率ドラッグ更新                 |    ✅    |   ✅   | **✅（担当タスクのみ）** |
| タスク・行・マーカーの通常編集                 |    ✅    |   ✅   |            ❌            |
| 行のインデント / アウトデント（WBS操作）       |    ✅    |   ✅   |            ❌            |
| スナップショット作成・コメント追加             |    ✅    |   ✅   |            ❌            |
| 編集オプション（進捗管理・行移動禁止等）の変更 |    ✅    |   ❌   |            ❌            |
| プロジェクト設定・削除                         |    ✅    |   ❌   |            ❌            |
| APIキー管理                                    |    ✅    |   ❌   |            ❌            |

特に実務で重宝するのが**「担当者による進捗更新」**の分離です。現場のメンバーに「閲覧者（Viewer）」権限を付与しておけば、プロジェクト全体のタスク日程や行構造を誤って崩される心配がありません。その上で、各メンバーは自分が担当するタスクの進捗率だけはチャート上で直接ドラッグ操作でスムーズに更新・報告できます。安全性と現場の入力しやすさを両立した、実践的な権限UX設計です。

また、権限付与時のメールアドレス履歴補完や、公開プロジェクト用URLによるゲスト共有など、運用の手間を最小限に抑える工夫を取り入れています。

## 表示設定メニューの刷新 ＆ テーマ対応

画面上部右側の ⚙️（設定アイコン）から開く「表示設定メニュー」は、操作性と一覧性を極限まで高めるためUIを全面的に刷新しています。

- **リストレイアウトの統一**: 各行を「左：アイコン＋項目名」「右：操作コントロール」の共通フォーマットに統一。スイッチやコントロールが右端に整然と並び、迷わず操作できます
- **セグメントボタンによるワンタップ切替**: 「カレンダー幅」「行の高さ（極小〜特大）」「バーの影（なし〜大）」にコンパクトなボタングループを採用。従来のドロップダウンを開く手数をなくし、1クリックで直感的に切り替えられます
- **モダンなテーマカードUI**: ライト / ダーク / システム連動の切り替えに、視覚的なサムネイルカードUIを採用。選択中のテーマには枠線ハイライトとチェックバッジが付き、ひと目で把握できます
- **3セクションによる構造化**: 「表示項目」「サイズ・配置」「テーマ」の3カテゴリにすっきり整理されています

## ゲストログインで今すぐ試せる

**[MoguChart](https://moguchart.jp/)** では、「アカウント登録前にまず触ってみたい」という方のために、**ゲストログイン**を用意しています。

- Googleアカウント連携不要
- 「ゲストとしてログインする」ボタンを1クリックするだけですぐに開始
- 作成したデータは約24時間後に自動クリーンアップ

気軽に試してみて、気に入ったらGoogleアカウントでログインすれば、いつでも永続的にプロジェクトを保存・管理できます。

## おわりに

MoguChart は「**ガントチャートだけをちゃんとやる**」をコンセプトに開発を続けてきました。

メジャーバージョン **v1.0.0** での **WBS階層ツリー構造** と **サマリータスク自動集計** の全面サポートを経て、最新 **v1.1.0** では **公式 Vue 3 ラッパーの導入**、**エクスポートプラグインの遅延読み込みによる初期ロード高速化**、**画像プレビューポップアップのホバーディレイ改善**、そして **ズーム倍率自動正規化エクスポート** など、日々の操作感と品質をさらに高めるアップデートを実施しました。

フォントやバーが美しく連動する表示倍率ズームシステム、Chromeライクなズーム操作UI、カレンダー横幅の独立設定、セグメントボタン導入による表示設定メニューUIなど、中〜大規模プロジェクトをサクサク心地よく動かすための体験を徹底的に磨き上げています。

余計な機能で複雑化させず、でも「これが欲しかった」という機能は妥協なく揃えている ─ そんな"ちょうどいい"ツールを目指して、これからも継続してアップデートを行っていきます。
